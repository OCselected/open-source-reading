# 一纸读书法（One-Page Reading Method）

> 来源：浅田すぐる《紙1枚! 読書法》+ Alx AI 增强版
> 角色定位：阅读入口层——读完当下即刻结构化，产物分别流入 daily-reading / wiki / breakpoints 三条轨道。
> 不替代现有流程，是入口端的补充。

---

## 核心结构（A4 单页）

```
┌──────────────────────────────────────────────────────────┐
│  书名 / 作者 / 日期                                       │
├─────────────────────┬────────────────────────────────────┤
│  左半 · 人填 (2min)  │  右半 · AI 填 (2min)                 │
│                     │                                    │
│  核心观点 (3-5 论点)  │  关键问题                            │
│   -                │   - 有什么没说的？                    │
│   -                │   - 反面是什么？                      │
│   -                │   - 如何验证？                        │
│                     │   - 5 年后还成立吗？                 │
│  关键事实            │                                    │
│   - [数据/案例] p.xx │  答案与盲区                        │
│   - [数据/案例] p.xx │   - AI 基于事实回答                │
│                     │   - 盲区在哪里？                    │
│  好奇点（人想知道）   │                                    │
│   -                │  最小可执行行动                        │
│   -                │   - 本周做一件小事                    │
│                     │   - 人负责落地                      │
├─────────────────────┴────────────────────────────────────┤
│  产物流向                                                  │
│  感慨 → daily-reading/YYYY-MM-DD.md                      │
│  制度分析 → wiki/raw/articles/                           │
│  断点 → reading-breakpoints 追踪                          │
└──────────────────────────────────────────────────────────┘
```

---

## 与 open-source-reading 三轨道的映射

| 一纸读书法产出 | 流入轨道 | 触发条件 |
|---|---|---|
| 核心观点 + 适兕感慨 | daily-reading（书摘 + 感慨 slide） | 有"读后即兴" |
| 制度/产权/治理分析 | wiki/raw/articles/ | 涉及制度经济学框架 |
| 阅读断点（从 X 跳到了 Y） | reading-breakpoints | 多书并行或思路跳跃 |
| 最小可执行行动 | daily-reading 结尾 slide | 本周要落地的事 |
| 5年后还成立？ | wiki/queries/（留白问题） | 有认知不确定性 |

## 人机分工协议

**人（适兕）**
- 填左半：观点、事实、好奇点
- 决策：本周做一件什么事
- 判断：产物流哪条轨道

**AI（窄廊）**
- 填右半：关键问题、盲区、答案
- 提示：5年后视角、反面假设
- 归档：把填好的内容按轨道写入文件

## 与现有 skill 的关系

| Skill | 关系 |
|---|---|
| daily-reading-slide-deck | 一纸读书法是**入口**，daily-reading 是**出口之一** |
| reading-breakpoints | 一纸读书法的断点识别直接送入 breakpoints |
| openlibrary | 一纸读书法的"关键事实"引用须经过 openlibrary 验证 |

---

## 使用流程

1. **人填左半**（读完立刻，≤2 分钟）
2. **AI 填右半**（窄廊基于全文 + 左半产出，≤2 分钟）
3. **人定行动**（本周做一件小事）
4. **归档**：按"产物流向"写入对应文件
5. **Git**：所有轨道文件单独 commit + push

---

## 备注

- 一纸读书法的模板文件是 A4 纸质（浅田原版），电子版建议用 Notion 或 Feishu Wiki 单页
- 产物流向**不是强制的**——有些书读完只产生感慨（仅 daily-reading），有些产生制度分析（仅 wiki）
- "5 年后还成立？"是 Alx 版的补充，浅田原版没有——这个角度在「开源之道」实践中特别有价值（用于评估制度性判断的半衰期）
