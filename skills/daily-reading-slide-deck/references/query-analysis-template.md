# 适兕即兴分析模板（Query Analysis Pattern）

> 来源：2026-08-01 连续 6+ 篇 wiki 分析的归纳。当适兕对一篇文章（机构动态、政策、新闻）给出即兴判断时，wiki 的 `queries/` 文件遵循此结构。

## 触发条件

- 适兕发送一段即兴判断（"适兕感慨"、"适兕即兴"、"适兕判断"）
- 适兕发送一篇文章链接并要求分析
- 适兕对某机构/政策/事件给出制度分析

## 五步结构

1. **适兕原话**（原封不动引用，不扩写不修饰）——这是分析的唯一合法来源
2. **适兕核心判断**（逐条，用"适兕判断一/二/三"标注，不可扩写成段落）
3. **适兕留白**（1-2 句，不是总结，是延伸问题）
4. **适兕留白**中**禁止出现"适兕判断"**——留白是问题，不是结论
5. **原文链接**（附在文末，wiki 和 slide 都要）

## 语言风格

- 用 `**适兕判断：**` 而非"适兕认为"、"适兕觉得"
- 判断是**一句话**，不是一整段——长判断分条
- 不用"首先/其次/最后"，用编号（一/二/三）或"判断一/判断二"
- 不写"适兕说"——直接写判断

## 与 wiki 的关系

wiki `queries/` 文件使用此模板，slide 使用模板（`template.md`）结构但内容来源是此模板的判断。

## 典型适兕判断句式（今天出现的）

- "没有人错——就是制度安排，以及对制度安排的认知和服从"
- "当制度取消了人的主体性，它还能用'开源'来装饰自己"
- "L3制造的不是市场，是一个'服从市场'"
- "否定制度意味着否定自我——需要强大的勇气"
- "任何人被制度选中，都会被制度重新设计"
